# 业务场景库（示例）

## SC-001 正常提交申请

| 项目 | 内容 |
|---|---|
| 角色 | 申请人 |
| 对象 | 项目申请 |
| 当前状态 | 草稿 |
| 前置条件 | 当前批次开放申报，信息完整 |
| 操作 | 提交 |
| 结果 | 进入待审核状态 |
| 相关规则 | BR-001 |

## SC-002 无专家评审的正常审核

| 项目 | 内容 |
|---|---|
| 角色 | 审核人员 |
| 对象 | 项目申请 |
| 当前状态 | 审核中 |
| 条件 | 审核通过；项目规则不要求专家评审 |
| 结果 | 跳过专家评审，进入下一业务阶段 |
| 相关规则 | BR-002 |

## SC-003 审核驳回后重新提交

| 项目 | 内容 |
|---|---|
| 角色 | 申请人 |
| 对象 | 项目申请 |
| 当前状态 | 已驳回 |
| 操作 | 修改并重新提交 |
| 结果 | 再次进入审核 |
| 相关规则 | BR-003 |
