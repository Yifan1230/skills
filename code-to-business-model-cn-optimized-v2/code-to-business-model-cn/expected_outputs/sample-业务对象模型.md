# 业务对象模型（示例）

> 仅用于展示输出颗粒度。

## BO-001 项目种类

**定义**：一组相对稳定的项目管理规则，用于规定某类项目如何申报、审核和过程管理。

**主要关系**：
- 可以产生多个项目批次
- 可以关联评审规则
- 可以定义是否需要中期检查

## BO-002 项目批次

**定义**：项目种类在某个具体时间范围内的一次执行。

**上级对象**：BO-001 项目种类

**下级对象**：项目申请、立项项目

**主要状态**：草稿 → 已发布 → 已结束

## 对象关系

```text
项目种类
   ↓ 产生
项目批次
   ↓ 接收
项目申请
   ↓ 审核通过后形成
项目
   ├─ 中期检查
   └─ 结项
```
