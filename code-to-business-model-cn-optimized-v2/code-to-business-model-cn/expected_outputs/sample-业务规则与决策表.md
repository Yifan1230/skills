# 业务规则与决策表（示例）

## BR-001 申报时间规则

只有当前时间处于项目批次申报开放期内，申请人才可以提交项目申请。

**影响**：开放期内允许提交；开放期外不可提交。

## BR-002 专家评审进入规则

审核通过后，是否进入专家评审由项目规则决定。

### DT-001 专家评审决策表

| 条件 | 情况A | 情况B | 情况C |
|---|---|---|---|
| 是否需要专家评审 | 否 | 是 | 是 |
| 评审方式 | - | 普通 | 盲审 |
| 后续流程 | 直接进入下一阶段 | 普通专家评审 | 隐藏身份后评审 |

## BR-003 驳回规则

审核人员驳回申请后，申请重新进入可修改状态。
