# 生命周期（示例）

## 项目申请生命周期

| 当前状态 | 操作/事件 | 条件 | 角色 | 下一状态 | 后续影响 |
|---|---|---|---|---|---|
| 草稿 | 提交 | 当前批次开放且信息完整 | 申请人 | 待学院审核 | 进入审核流程 |
| 待学院审核 | 通过 | 审核同意 | 学院管理员 | 待学校审核 | 进入下一审核节点 |
| 待学院审核 | 驳回 | 审核不同意 | 学院管理员 | 已驳回 | 申请人可以修改 |
| 已驳回 | 重新提交 | 修改完成 | 申请人 | 待学院审核 | 重新进入审核 |
| 待审核 | 撤回 | 系统允许撤回 | 申请人 | 草稿 | 恢复编辑 |

```text
草稿
 ↓ 提交
待学院审核
 ├─ 驳回 → 已驳回 → 修改 → 重新提交
 └─ 通过 → 待学校审核
```

【待确认】学校审核阶段是否允许申请人撤回。
