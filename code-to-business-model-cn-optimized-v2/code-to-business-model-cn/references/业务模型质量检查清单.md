# 业务模型质量检查清单

## 业务对象
- [ ] 核心主对象已识别
- [ ] 配置对象、过程对象、结果对象和记录已区分
- [ ] 对象关系清楚
- [ ] 未把页面或技术表直接当业务模型

## 生命周期
- [ ] 主要状态都有业务解释
- [ ] 状态进入和离开条件明确
- [ ] 驳回、撤回、终止、延期、恢复等逆向路径已覆盖
- [ ] 无法解释的状态进入待确认清单

## 业务规则
- [ ] 关键操作都有前置条件
- [ ] 状态、角色、类型、配置、时间、数量差异已检查

## 场景
- [ ] 主流程场景完整
- [ ] 重要分支完整
- [ ] 异常场景完整
- [ ] 场景不是机械穷举
- [ ] 每个场景能关联到业务规则

## 权限与配置
- [ ] 角色、操作权限、数据范围已梳理
- [ ] 会改变业务流程的配置已单独梳理
- [ ] 配置作用范围与默认值已说明

## 端到端流程
- [ ] 已跨页面串起业务过程
- [ ] 主流程和异常流程可区分
- [ ] 每个节点能说明谁、处理什么、什么条件、处理后去哪

## 覆盖
- [ ] 状态无遗漏
- [ ] 业务类型无遗漏
- [ ] 关键分支无遗漏
- [ ] 权限差异无遗漏
- [ ] 配置差异无遗漏
- [ ] 无法确认的内容没有被强行解释
