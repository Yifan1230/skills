# 大型系统分批分析指南

大型系统不要一次性深挖全部源码。

## 第1轮：全局地图
只输出系统模块、主要角色、主要业务入口和候选业务对象。

## 第2轮：逐业务域深入
每个业务域固定按：

**业务对象 → 生命周期 → 规则 → 分支 → 场景 → 页面映射**

完成后再进入下一个业务域。

## 第3轮：跨模块合并
重点解决：
- 同一对象不同叫法；
- 一个流程跨多个模块；
- 跨模块状态变化；
- 跨模块配置影响。

## 第4轮：专项补漏
分别按状态、权限、配置、异常、自动处理、特殊客户逻辑再扫一遍。

## 第5轮：覆盖审计
生成最终覆盖表和待确认问题。

## 进度文件
长期分析维护 `_progress.md`：
- 已完成模块
- 当前模块
- 待分析模块
- 已分配业务对象编号
- 已分配业务规则编号
- 已分配场景编号
- 待确认问题
- 当前覆盖情况
