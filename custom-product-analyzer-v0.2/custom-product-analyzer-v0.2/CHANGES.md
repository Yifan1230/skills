# v0.2 Changes

## 核心修复

V0.1 的最终“产品化建议”仍可能停留在技术/分类语言，例如：

```text
学生名单导入验证规则 → configuration_candidate
排课教室/前端/日期控制等版本漂移项 → observe
NJU hutool 嵌入、XHCOM 等定制模块 → keep_custom
```

V0.2 将这些内部分类与产品经理视图彻底分离。

## 新增

- `references/product-problem-analysis.md`
- `templates/product-problem.schema.json`
- `templates/product-manager-report-template.md`
- Stage 9 改为 `Product Problem Recovery & Productization Analysis`
- 产品问题识别 Gate
- 六步产品翻译法
- 产品问题卡 Product Problem Card
- 技术特例隔离区
- 中文建议标签
- 产品经理视图优先的报告格式

## 新的主输出链路

```text
Change Unit
→ Feature
→ 用户行为变化
→ 业务场景/角色
→ 标品限制
→ 客户定制原因

→ 产品能力方案
```
