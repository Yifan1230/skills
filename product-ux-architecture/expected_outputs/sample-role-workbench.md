# 教师工作台（示例）

## 角色任务地图

| 任务 | 频率 | 时效 | 风险 | 推荐入口 |
|---|---|---|---|---|
| 成绩录入 | 学期高频 | 高 | 高 | 工作台待办 |
| 调课申请 | 中频 | 中 | 中 | 常用场景 |
| 论文审核 | 周期性 | 高 | 高 | 待办 |
| 查询课表 | 高频 | 低 | 低 | 快速入口/自然语言 |

## 工作台结构

```text
我的待办
├─ 3门课程待录成绩
├─ 2名学生论文待审核
└─ 1项调课申请待处理

今日教学
├─ 10:00 高等数学
└─ 14:00 数据结构

异常提醒
└─ 1门课程成绩分布异常

常用入口
├─ 查课表
├─ 成绩录入
└─ 调课申请
```

## 数据到行动

“未提交成绩 3门”不只显示数字，还可：

```text
查看课程
→ 进入录入
→ 批量校验
→ 提交
```

## 多身份

若该教师同时为导师/评审专家：

- 待办统一聚合；
- 按“教学 / 导师 / 评审”分组；
- 关键审核动作明确当前责任身份；
- 不要求先切换账号或用户组。
