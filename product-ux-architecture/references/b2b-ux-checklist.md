# B端改版体验检查清单

## 场景
- [ ] 页面对应明确业务场景
- [ ] 主任务清楚
- [ ] 高频任务路径足够短

## 信息架构
- [ ] 高频业务没有被低频配置淹没
- [ ] 菜单层级可理解
- [ ] 同一业务对象没有无理由散落多个模块

## 状态与流程
- [ ] 当前阶段清楚
- [ ] 下一步清楚
- [ ] 当前责任角色清楚
- [ ] 驳回/失败后知道怎么办

## 效率
- [ ] 管理端有合理批量能力
- [ ] 不重复填写已有数据
- [ ] 不重复设置相同筛选条件
- [ ] 不存在无价值跳转

## 权限
- [ ] 用户理解为什么能/不能操作
- [ ] 多身份责任边界清楚

## 数据
- [ ] 指标能继续定位明细
- [ ] 异常能继续发起行动
- [ ] 行动后有处理反馈

## 配置
- [ ] 有合理默认值
- [ ] 高级配置按需展开
- [ ] 配置影响范围明确
- [ ] 冲突组合有校验

## AI
- [ ] AI减少实际工作量
- [ ] 高责任建议有原因说明
- [ ] 高影响动作保留人工确认
- [ ] 不强迫用户通过聊天完成所有业务
