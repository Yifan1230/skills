# 工作台与任务中心模式

## 工作台不是功能入口集合

工作台优先组织“当前要做的事情”，而不是把所有模块做成宫格。

建议结构：

```text
当前最重要任务
即将截止
异常/风险
业务进度
常用入口
数据概览
```

## 任务卡片至少说明

- 什么事情；
- 为什么现在需要处理；
- 对象是谁/是什么；
- 截止时间；
- 当前状态；
- 能否直接办理。

## 消息、待办、流程关系

优先统一为：

```text
业务事件
→ 产生任务
→ 通知
→ 办理
→ 业务状态变化
```

不要分别建设互不关联的消息中心、待办中心和流程中心。

## 多身份

可以统一展示任务，但建议按业务身份或场景分组。

执行高责任操作时，应明确当前责任身份。

## 管理端

管理人员工作台重点通常是：

- 业务进度
- 待处理数量
- 异常数量
- 即将截止
- 批量动作

而不是个人信息展示。
