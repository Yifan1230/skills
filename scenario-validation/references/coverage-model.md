# 业务场景覆盖模型

## 1. 覆盖不是只算场景数量

至少从以下维度检查：

- 业务对象
- 状态
- 角色
- 权限范围
- 业务规则
- 配置
- 异常路径
- 迁移状态

## 2. 优先级

高风险场景优先于低风险场景数量。

例如：

- 权限越权
- 状态错误迁移
- 结果不可逆
- 在途任务丢失

即使只涉及少量用户，也可能属于P0/P1。

## 3. 规则覆盖

每条关键规则至少检查：

```text
允许条件
禁止条件
状态差异
角色差异
配置差异
边界值
异常恢复
```

## 4. 状态覆盖

每个状态至少确认：

- 如何进入
- 可以做什么
- 不能做什么
- 如何离开
- 是否终态

## 5. 配置覆盖

只覆盖系统允许的合法组合。

对非法组合，验证系统是否阻止或给予明确提示。

## 6. 最终报告

覆盖率应和高风险未覆盖项一起展示。

不能出现：

> 覆盖率95%，因此可以上线。

如果剩余5%包含核心权限或在途迁移，仍然不应通过。
